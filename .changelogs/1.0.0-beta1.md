# Qz-UILib-Compat 1.0.0-beta1

`Qz-UILib-Compat` 首次独立预发布。本组件为可选的 Forge 1.7.10 专用兼容 Mod（输出 Java 8 字节码），配套 `Qz-UILib 5.0.0-beta3` 使用，集中提供 Angelica/Iris 光影字体管线适配、AE2 监控字体缓存修复以及 GTNH 私用显示字符映射。

## 主要更新

### Angelica、AE2 与光影适配

- **按需安全加载**：按目标类与精确方法签名选择性启用适配，目标 Mod 缺席时不加载对应实现。
- **Angelica 字体管线与崩溃修复**：适配 Angelica `2.2.10` 与 `2.2.28` 的字体管线，处理显示列表的逻辑捕获、回放与暂停所有权；修正 Angelica 枚举输入状态导致的开启光影崩溃问题，协调字体提交边界。
- **光影属性与输出保持**：适配 BSL 光影中点纹理属性维度及完整输入布局，保留 Iris 字体 pass 的实际输出目标（#74）。*（注：不承诺兼容任意光影包或任意 Angelica 版本。）*
- **UniMixins 兼容**：修正 UniMixins 重映射后产生的插件重复方法问题（#69）。
- **AE2 监控缓存同步**：修正 AE2 存储、转换与吞吐监控的字体列表缓存，使其随字体替换开关和排版代际重新生成，避免旧字形与新字形混存，完整保留原有业务逻辑及六向放置特性（#69）。

### GTNH 字符映射

- **私用字符完整覆盖**：完整覆盖 `U+E000`—`U+E020` 共 33 项私用显示字符（#53）。其中 20 项沿用上游实际登记的对应关系，其余 13 项采用选定的近似 Unicode 字符。
- **特定符号映射规则**：硫黄采用普通炼金硫黄符号 `U+1F70D`；部分替代仅取外观形似（`GALAXY` 使用 `U+058D`；问号采用 `U+FE56`，不宣称等价下标，不做额外缩小或下移处理）。
- **无侵入字体选择**：仅执行码点重映射，不修改业务原文、不绑定特定字体；字体选择完全复用 Core 现有的候选排序系统。
- **独立配置与热重载**：配置文件位于 `config/qz_uilib_compat.yaml`。`gtnh.mapPrivateCharacters` 默认为 `true`（设为 `false` 可关闭）；修改配置后按 `F3+T` 重载资源或重启游戏即可生效，绘制热路径不读取配置文件。

## 升级或安装说明

- **适用范围与版本配套**：本组件仅适用于 Minecraft Forge 1.7.10（**不可用于其他 Minecraft 版本**），自身版本为 `1.0.0-beta1`，必须与 `Qz-UILib`（Core、Platform、Minecraft）`5.0.0-beta3` 配套安装。
- **按需安装**：当 Forge 1.7.10 / GTNH 环境中使用了 Angelica、lwjgl3ify/RFB、AE2，或需要启用 GTNH 私用字符映射时，请额外安装本 Mod。
- **存量字体配置提示**：已保存完整 `font.candidates` 列表的用户不会自动获得 Core 新增的默认符号字体。若需显示 `U+1F70D`（炼金硫黄符号）等字符，请在字体设置中手动将 `builtin:noto-symbols` 添加至列表末尾（保留已有排序）。
- **开源许可**：项目自有代码采用 MIT 许可证。
