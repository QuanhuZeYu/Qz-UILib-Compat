# Qz-UILib Compat 1.0.0-beta3

## 更新

- 适配 Angelica 2.2.43 拆分后的 GL 状态入口，修正查询、状态恢复与 Iris 渲染状态应用的 ABI 接入。
- 将 GTNH 2.9.0 正式组合加入实际发行 Jar 的验证矩阵，覆盖 Angelica `2.2.43` 与 AE2 `rv3-beta-1095-GTNH`，保留已有版本检查。

## 配套

配套 Qz-UILib Core、Platform 与 Minecraft `5.0.0-beta5`。Compat 独立安装，按已安装的可选 Mod 选择适配。
